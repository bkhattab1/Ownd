# OWND — Profile Setup, SEO and Copy (Instagram + TikTok, Darija / French / English)

Date: 2026-10-06. What the apps index comes from third-party 2026 guides ([Inro](https://www.inro.social/blog/instagram-seo), [BlitzCut](https://blitzcutai.com/blog/tiktok-seo-guide-2026)), not from Instagram or TikTok themselves, so treat the weights as good guidance, not rules. ## 1. What the apps read (so we put keywords in the right places)

| Where | Instagram | TikTok |
|---|---|---|
| **Name field** (the bold name, not @handle) | Heavily weighted. Put the keyword here. | Not confirmed by the guide I read; do it anyway, it costs nothing |
| **Bio** | Say who you are in the words a searcher would type | Short (80 chars), same keywords |
| **Caption, first line** | Acts like a headline; put the keyword here once | Keyword + one context sentence + 3–5 hashtags |
| **Spoken words / on-screen text** | Reels on-screen text is read | **Very high weight**: say the keyword in the first seconds *and* show it as text |
| **Alt text** | Read by Instagram and Google; write it yourself | n/a |
| **Hashtags** | Minor now; 3–5 specific ones | Medium; 3–5 niche ones, not 20 generic |
| **Saves, shares, comments** | Matter more than likes | High |

## 2. Find the real keywords Moroccans type (free, 10 minutes)

Moroccan users search in several scripts. Type each into Instagram and TikTok search and write down the **autocomplete suggestions** and the number of posts:

- Latin / French: `streetwear maroc`, `hoodie maroc`, `hoodie oversize casablanca`, `marque marocaine`, `vetement streetwear maroc`, `livraison maroc`
- Arabizi: `streetwear maghribi`, `hoodie bi taman mnasb`, `7oodie`
- Arabic script: `ستريت وير المغرب`, `هودي`, `ماركة مغربية`
- English: `moroccan streetwear`, `oversized hoodie morocco`

Keep the 5–8 phrases with visible autocomplete and a healthy number of posts. Replace my guesses below with what you find.

## 4. Caption formula (every post)

```
Line 1: keyword headline (what + for whom), once
Line 2-3: the story or hook in Darija / FR (natural, not stuffed)
Line 4: one call to action (LIST / link / comment)
Line 5: 3–5 hashtags
```

## 5. Videos (TikTok and Reels)

1. **Say the keyword in the first 3 seconds**, in Darija or French: "Hna hoodie streetwear marocain..."
2. **Burn it in as on-screen text** at the same moment (both apps read it).
3. Add **subtitles** (auto-captions are fine, fix the Darija).
4. Caption follows Section 4.
5. Cover frame: bold 3–4 words, keyword included.

## 6. Alt text templates (Instagram, write it in "Advanced settings")

- `Hoodie streetwear marocain oversize crème avec logo OWND, Chapter 01`
- `Moroccan streetwear hoodie in cream with the OWND logo, numbered edition`
- `Personne masquée portant un hoodie OWND dans une rue de Casablanca`

## 7. Language mix rules

- **Brand voice** = Darija in Latin letters, short and direct.
- **Searchable words** (hoodie, streetwear, Maroc, livraison, paiement à la livraison) in **French/English**, placed in the name, bio and first caption line.
- **One line in Arabic script** in the bio or occasionally in captions (for people searching in Arabic), e.g. `هودي مغربي · ستريت وير`.
- Never write the same caption three times in three languages; pick one main language per post and rotate.

## 8. Weekly check (15 minutes)

1. Which post brought the most profile visits, follows and "LIST" messages?
2. Which keyword did people use in comments and DMs? Use it in the next captions.
3. Instagram **Insights → reach by source**: how much comes from Explore and search? Double down on the formats that bring search traffic.
4. Update the bio only once every 2 weeks so you can see what changed.
